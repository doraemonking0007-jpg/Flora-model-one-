# Floral Knots website

This is a small static website. Open `index.html` in a browser to preview it. The product photos and logo are in `assets/`.

Order links point to the Floral Knots Instagram profile. To change the profile link or product descriptions, edit `index.html`.

To publish it with GitHub Pages, put these files in a GitHub repository and enable Pages for the main branch. A custom domain can be connected later.
